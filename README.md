A Python program that draws a complete newspaper front page for Monday
23 November 2026 entirely from code — no image files, no network,
standard library only. A small software canvas and an embedded 5x7
bitmap typeface render the masthead, the COP31 collapse in Antalya as
the lead story, panels on the Strait of Hormuz tanker crisis and the
Houthi strikes on Riyadh, briefs on the Kyiv-region drone strike, the
South Korean education minister's resignation and the Nepal-India
talks in New Delhi, plus a news ticker. The finished page is written
as a PNG by a built-in encoder, and two runs produce byte-identical
output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
